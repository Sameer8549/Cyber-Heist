FONTS REQUIRED (place woff2 files here):

1. Cabinet Grotesk (free from fontshare.com/fonts/cabinet-grotesk)
   Files needed: CabinetGrotesk-Regular.woff2, CabinetGrotesk-Medium.woff2,
                 CabinetGrotesk-SemiBold.woff2, CabinetGrotesk-Bold.woff2

2. JetBrains Mono (open source, download from jetbrains.com/lp/mono/)
   Files needed: JetBrainsMono-Regular.woff2, JetBrainsMono-Medium.woff2

The app works without them (system mono/sans fallback), but the design
requires these fonts for the correct aesthetic.
